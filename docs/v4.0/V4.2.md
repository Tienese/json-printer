## Summary
Implements Grammar Coach V4.1 with conjugation-based validation, DIRTY workflow, seed data, and V3 cleanup.
## Changes
### Phase 1: Conjugation Infrastructure
- **NEW** `ConjugationMapper.java` - Maps Sudachi conjugation forms to friendly names (te-form, masu-stem, etc.)
- Enhanced `hasVerbForm()` in `SentenceValidationService` to use ConjugationMapper
### Phase 2: Rule Type Implementations
- `evaluatePatternRule()` - Pattern matching across token stream
- `evaluateVerbParticleRule()` - Full implementation for edge case verbs
- `REQUIRES_PARTICLE` condition type support
### Phase 3: DIRTY Workflow
- **NEW** `VocabService.java` - Triggers DIRTY resolution when vocab is added
- Updated `SentenceService.save()` - Detects unknown vocab and sets DIRTY status
### Phase 4: Seed Data & Cleanup
- **NEW** `pattern-rules-seed.json` - 4 pattern rules (てください, なければなりません, ないでください, たいです)
- **NEW** `verb-particle-rules-seed.json` - 4 verb-particle rules (住む→に, 働く→で, 勤める→に, 会う→に)
- **NEW** `SeedDataService.java` - Auto-loads rules on startup via @PostConstruct
- `GrammarRule.java` marked `@Deprecated(since=\"4.1\", forRemoval=true)`
- Updated Kuromoji comments → Sudachi
