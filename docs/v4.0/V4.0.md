## 1. Executive Summary

### 1.1 Problem Statement
Grammar Coach V3.0 performs structural validation only. It cannot detect semantic errors like "食堂を食べます" (eating a cafeteria) because it lacks:
1. A sentence bank for storing/testing example sentences
2. Tag-based semantic rules (e.g., "object of 食べる must be edible")
3. Modern tokenizer with conjugation detection

### 1.2 Proposed Solution
V4.0 introduces:
- **5 new database entities** for sentences, rules, and conditions
- **Sudachi tokenizer** replacing Kuromoji (better conjugation, normalization, larger lexicon)
- **SentenceValidationService** for tag-based semantic validation
- **REST API** for CRUD operations on all new entities
- **Minimal frontend** pages (functional, not polished - V4.2 handles UI/UX)

### 1.3 Success Metrics
| Metric | Target |
|--------|--------|
| Entities created | 5 new entities with repositories |
| Sudachi integration | All tokenization uses Sudachi Mode B |
| Validation accuracy | Correctly flags "食堂を食べます" as invalid |
| API coverage | All CRUD endpoints functional |
| Frontend pages | 3 basic pages (vocab, sentences, rules) |

### 1.4 Complexity Rating
**COMPLEX** - 15+ files across backend and frontend, Sudachi integration, new validation engine

#### 4.2.3 SudachiTokenizerService Implementation
```java
@Service
public class SudachiTokenizerService implements TokenizerService {
    
    private final Tokenizer tokenizer;
    
    public SudachiTokenizerService() throws IOException {
        // Load Sudachi with Mode B (middle segmentation)
        Dictionary dict = new DictionaryFactory().create();
        this.tokenizer = dict.create();
    }
    
    @Override
    public List<TokenResult> tokenize(String text) {
        List<Morpheme> morphemes = tokenizer.tokenize(
            Tokenizer.SplitMode.B,  // Mode B for compound nouns
            text
        );
        
        return morphemes.stream()
            .map(this::toTokenResult)
            .collect(Collectors.toList());
    }
    
    private TokenResult toTokenResult(Morpheme m) {
        String[] posParts = m.partOfSpeech().toArray(new String[0]);
        return new TokenResult(
            m.surface(),
            m.dictionaryForm(),
            String.join(",", posParts),
            posParts.length > 0 ? posParts[0] : "",
            m.readingForm(),
            m.begin(),
            m.end(),
            posParts.length > 4 ? posParts[4] : null,  // conjugationType
            posParts.length > 5 ? posParts[5] : null,  // conjugationForm
            m.normalizedForm()
        );
    }
}
```

```java
private List<ViolationDTO> evaluateParticleRule(
        GrammarRuleV4 rule, 
        List<TokenResult> tokens) {
    List<ViolationDTO> violations = new ArrayList<>();
    
    // Find particle occurrences
    for (int i = 0; i < tokens.size(); i++) {
        TokenResult token = tokens.get(i);
        if (token.posLevel1().equals("助詞") && 
            token.surface().equals(rule.getParticle())) {
            
            // Get conditions for this rule
            List<RuleCondition> conditions = conditionRepo
                .findByRuleIdOrderByConditionOrder(rule.getId());
            
            // Evaluate each condition
            for (RuleCondition cond : conditions) {
                TokenResult target = getTargetToken(tokens, i, cond.getTargetPosition());
                if (target != null && !evaluateCondition(cond, target)) {
                    violations.add(new ViolationDTO(
                        rule.getId(),
                        rule.getName(),
                        cond.getErrorMessage().replace("{word}", target.surface()),
                        target.startOffset(),
                        target.surface()
                    ));
                }
            }
        }
    }
    return violations;
}
```

private TokenResult getTargetToken(List<TokenResult> tokens, int particleIndex, String position) {
    switch (position) {
        case "BEFORE": return particleIndex > 0 ? tokens.get(particleIndex - 1) : null;
        case "AFTER": return particleIndex < tokens.size() - 1 ? tokens.get(particleIndex + 1) : null;
        case "OBJECT": return findObjectToken(tokens, particleIndex);
        case "VERB": return findVerbToken(tokens);
        default: return null;
    }
}

private boolean evaluateCondition(RuleCondition cond, TokenResult token) {
    switch (cond.getConditionType()) {
        case "HAS_TAG": return hasTag(token, cond.getConditionValue());
        case "NOT_HAS_TAG": return !hasTag(token, cond.getConditionValue());
        case "IS_VERB": return isVerb(token, cond.getConditionValue());
        case "VERB_FORM": return hasVerbForm(token, cond.getConditionValue());
        case "IS_POS": return token.posLevel1().equals(cond.getConditionValue());
        case "MATCHES": return token.surface().matches(cond.getConditionValue());
        default: return true;
    }
}
